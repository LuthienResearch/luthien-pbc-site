Control Tower

Control Tower is a framework for AI control evaluations built on Inspect and developed by EquiStamp, Redwood Research, and Luthien.

Docs Leaderboard GitHub

what it's for

  • Control Tower measures how well safety protocols work. It runs AI agents on tasks in realistic software environments.
  • It ships blue-team protocols, action- and trajectory-level monitors, control evaluations, safety-usefulness curves, and trajectory tooling.
  • Its public leaderboard reports how well frontier models complete their assigned tasks while a trusted monitor watches for sabotage.

built by

Control Tower is developed by EquiStamp, Redwood Research, and Luthien. The leaderboard is run by Redwood Research and EquiStamp.
